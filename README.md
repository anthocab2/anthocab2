### PEGazu

A reproducible quantitative financial research laboratory built as an independent software engineering and research project.

Its architecture focuses on separating:

```text
Evidence
    ↓
Versioned datasets
    ↓
Predeclared research
    ↓
Falsification
    ↓
Replication
    ↓
Further qualification
```

The project emphasizes:

- Deterministic request identities
- Immutable/idempotent persistence
- MongoDB Atlas
- External market-data acquisition
- Exact readback verification
- Dataset versioning
- Predeclared experiments
- Statistical evaluation
- Replication
- Reproducible research
- Honest retention of negative results

PEGazu is research software and does not assume that a statistical result implies a profitable trading strategy.

## 🧩 Engineering Principles

The more I build, the more I value software that is:

- **Testable** — behavior should be verifiable.
- **Deterministic** — the same inputs should produce explainable results.
- **Reproducible** — important results should be possible to reconstruct.
- **Auditable** — systems should preserve enough evidence to explain what happened.
- **Explicit** — assumptions, limits, and unknowns should remain visible.
- **Maintainable** — clear code and boundaries matter more than unnecessary complexity.
- **Incremental** — build, verify, then expand.
